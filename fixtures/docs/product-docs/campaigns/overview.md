# Campaigns Overview

A campaign is the top-level unit of work in the product: it groups one or
more ad sets, has a single objective (awareness, conversions, or app
installs), and runs against a single budget.

## Campaign types

- **Standard campaigns** run on a fixed budget and schedule.
- **Always-on campaigns** run continuously with a recurring monthly budget.
- **Flighted campaigns** run in discrete date-bounded bursts, each with its
  own budget allocation.

## Lifecycle

Campaigns move through draft, review, active, paused, and archived states.
Only campaigns in the active state spend budget. See the campaign budgets
doc for how spend is tracked against the assigned cap, and the targeting
doc for how audiences are defined.
